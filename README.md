StudyFlow — Student Task Planner

Project Overview

StudyFlow is a simple web application designed to help students organize their academic tasks, manage deadlines, and track their progress.

Goals

* Make it easier to organize university assignments.
* Keep track of deadlines and task priorities.
* Monitor completed and pending tasks.
* Provide a simple and user-friendly interface.

Planned Features

* Add, edit, and delete tasks.
* Set a task title, subject, deadline, and priority.
* Mark tasks as completed.
* Filter tasks by completion status.
* Display basic task statistics.

Technologies

* Python — main programming language.
* Flask — web framework.
* HTML and CSS — user interface.
* SQLite — local data storage.
* unittest — unit testing.
* Git and GitHub — version control.

Object-Oriented Design

The application is planned around several components:

* Task — represents an academic task.
* TaskManager — manages task operations.
* TaskRepository — handles data storage and retrieval.
* Flask routes and templates — provide the web interface.

Development Plan

1. Define requirements and project structure.
2. Implement the core task management functionality.
3. Create the web interface and data storage.
4. Add filtering and statistics.
5. Test the application and document the code.

Project Status

Stage 1 — Project planning. The requirements and technology choices are being defined. Implementation has not yet been completed.
